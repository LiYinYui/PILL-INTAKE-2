MY-PILLS — ОБЪЯСНЕНИЕ ПРОСТЫМИ СЛОВАМИ

1. ЧТО ВООБЩЕ ДЕЛАЕТ ПРОЕКТ

Это сайт-дневник приёма таблеток.
Python — отвечает за данные и правила работы.
HTML — задаёт, какие элементы есть на странице.
CSS — отвечает за внешний вид.
JavaScript — помогает кнопкам работать без прыжка страницы наверх.
Flask — соединяет Python и сайт.

2. САМЫЕ ВАЖНЫЕ ФАЙЛЫ

app.py — главная часть программы на Python.
index.html — разметка страницы: заголовки, кнопки, поля и карточки.
style.css — цвета, размеры, отступы и оформление.
app.js — помогает отправлять нажатия кнопок в Python без полной перезагрузки страницы.
data/medications.json — файл, в котором хранится список таблеток.
data/last_day.txt — дата, когда последний раз проверяли новый день.
requirements.txt — список библиотек, нужных для запуска.

3. КАК РАБОТАЕТ PYTHON

В начале app.py подключаются инструменты:
- json — читать и записывать файл с данными;
- date — узнавать сегодняшнюю дату;
- Path — удобно указывать путь к файлам;
- Flask — создавать сайт;
- request — получать то, что пользователь ввёл в форму;
- render_template — показывать HTML-страницу;
- redirect — возвращать пользователя на главную;
- flash — показывать сообщение, например «Препарат добавлен»;
- session — запоминать выбранную тему.

PILL_INFO — это словарь со справочной информацией о препаратах. Там в основном текст, а не сложная логика.

QUICK_ADD — список препаратов, которые можно добавить готовой кнопкой.

INFO_KEY_BY_NAME и QUICK_ADD_BY_KEY — небольшие словари-помощники. Они позволяют быстро найти информацию по названию или ключу.

4. ФУНКЦИИ

save_medications(medications)
Получает список препаратов и записывает его в medications.json. Благодаря этому список не пропадает после закрытия сайта.

load_medications()
Читает список из medications.json. Затем проверяет дату. Если сегодня уже другой день, ставит current_count = 0 у каждого препарата и сохраняет изменения. Поэтому отметки «выпито» сбрасываются каждый день.

add_medicine(name, daily_count, info_key=None)
Создаёт новую запись о препарате. В записи есть название, сколько приёмов запланировано за день и сколько уже отмечено. Новый счётчик всегда начинается с нуля.

home()
Возвращает браузер на главную страницу после действия с кнопкой.

index()
Открывает главную страницу. Получает список препаратов из load_medications() и передаёт его в HTML-шаблон.

add_medication()
Получает название и число приёмов из формы. Проверяет, что название не пустое, а число больше нуля. Если всё нормально, добавляет препарат.

quick_add_medication(key)
Добавляет один из готовых вариантов — например, витамин D. Ключ в адресе помогает понять, какой вариант выбрал пользователь.

medication_action(medicine_id, action)
Работает с кнопками на карточке препарата:
- take — отмечает один приём, увеличивая счётчик на 1;
- reset — обнуляет счётчик вручную;
- delete — удаляет препарат из списка.
Счётчик не увеличивается выше дневного количества.

 toggle_theme()
Переключает светлую тему на тёмную или наоборот.

5. ЧТО ОЗНАЧАЮТ ОСНОВНЫЕ СЛОВА

def — объявляет функцию, то есть набор действий с названием.
if — «если»: выполняет код только при условии.
else — «иначе»: выполняет другой вариант.
return — возвращает результат функции.
for — повторяет действия для каждого элемента списка.
with open(...) — безопасно открывает файл.
json.load(...) — читает данные из JSON-файла.
json.dump(...) — сохраняет данные в JSON-файл.
request.form — данные, которые пользователь отправил через форму.
@app.get("/") — указывает Flask, какую функцию вызвать, когда открывают главную страницу.
@app.post("/add") — указывает Flask, какую функцию вызвать при отправке формы добавления.

6. КАК РАБОТАЕТ СБРОС В ПОЛНОЧЬ

JavaScript в app.js рассчитывает, сколько времени осталось до 00:00, и обновляет страницу в полночь.
После обновления Python запускает load_medications(). Функция сравнивает сегодняшнюю дату с датой в last_day.txt.
Если дата изменилась, Python обнуляет счётчики всех препаратов и записывает новую дату.
Если сайт был закрыт в полночь, сброс всё равно произойдёт при следующем открытии сайта или следующем действии с данными.

7. ЧТО СКАЗАТЬ ПРЕПОДАВАТЕЛЮ

«Я использовала Flask, чтобы создать сайт на Python. Python обрабатывает добавление и удаление препаратов, отмечает приёмы и сохраняет список в JSON-файл. HTML задаёт структуру страницы, CSS отвечает за оформление, а JavaScript обновляет страницу без скачка прокрутки. Для ежедневного сброса программа сравнивает текущую дату с сохранённой. Когда наступает новый день, счётчики приёма обнуляются».

Важно: счётчик — это только отметка пользователя. Он не определяет дозировку лекарства и не заменяет назначения врача.
