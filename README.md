# My-pills — версия на Python

Учебная версия приложения My-pills. Название проекта оставлено без перевода, интерфейс переведён на русский язык.

## Что умеет приложение

- добавлять препараты через форму или кнопки быстрого добавления;
- показывать счётчик отмеченных приёмов за день;
- отмечать приём, сбрасывать счётчик и удалять препарат;
- показывать справочную карточку для шести популярных вариантов;
- переключать светлую и тёмную тему;
- сохранять список в `data/medications.json`, чтобы он не исчезал после закрытия программы;
- автоматически обнулять счётчики при наступлении нового дня в 00:00. Если сайт закрыт в полночь, сброс произойдёт при следующем открытии.

## Как запустить в Windows

1. Установи Python 3.10 или новее, если он ещё не установлен. Во время установки отметь **Add Python to PATH**.
2. Распакуй архив в обычную папку.
3. Дважды нажми `run.bat`. Скрипт установит Flask и запустит приложение.
4. Открой в браузере адрес `http://127.0.0.1:5000`.
5. Чтобы остановить приложение, вернись в окно терминала и нажми `Ctrl+C`.

Если `run.bat` не запускается, открой PowerShell в папке проекта и введи:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Затем открой `http://127.0.0.1:5000`.

## Как устроен код

- `app.py` — логика на Python: добавление, поиск, изменение счётчиков, удаление, переключение темы и чтение/запись данных.
- `templates/index.html` — HTML-разметка страницы. В ней сохранены классы и структура исходного проекта.
- `static/style.css` — запасные стили в том же фиолетовом оформлении.
- `static/app.js` — открывает мобильное меню, помогает обновлять страницу без прыжка прокрутки и обновляет страницу в полночь.
- `data/medications.json` — список сохранённых препаратов.
- `requirements.txt` — список библиотек Python.

## Оригинальное оформление

Страница сначала подключает локальные запасные стили, а затем оригинальный `css/style.css` из публичного репозитория:

`https://github.com/LiYinYui/My-pills` (стили загружаются через jsDelivr CDN)

Это позволяет использовать исходное оформление, включая мобильную адаптацию. Для загрузки оригинального CSS, шрифта и картинки меню требуется интернет. Если GitHub не загрузится, страница использует локальные запасные стили.

## Как объяснить проект преподавателю

1. **Flask** — небольшая библиотека Python, которая принимает запросы из браузера и возвращает HTML-страницу.
2. **Маршрут** — адрес, который выполняет определённую функцию. Например, `/add` обрабатывает добавление препарата, а `/theme` меняет тему.
3. **Функция `load_medications()`** читает JSON-файл и проверяет дату. Если начался новый день, она обнуляет счётчики.
4. **Функция `save_medications()`** записывает обновлённый список в файл. Поэтому данные сохраняются между запусками.
5. **`add_medicine()`** создаёт запись с названием, числом приёмов и нулевым счётчиком.
6. **`medication_action()`** увеличивает счётчик, сбрасывает его или удаляет выбранную запись.
7. **HTML-шаблон** отображает значения, которые передал Python. Выражения вида `{{ med.name }}` вставляют данные в страницу.
8. **CSS** задаёт цвета, отступы, карточки и адаптацию под маленький экран.
9. Файл `ПОНЯТНОЕ_ОБЪЯСНЕНИЕ.txt` содержит простое объяснение кода и текст, который можно рассказать преподавателю.

Счётчик в приложении нужен для отметок пользователя и сам по себе не определяет медицинскую дозировку и не отправляет напоминания. Справочные сведения не заменяют инструкцию к препарату или консультацию специалиста.

При нажатии кнопок браузер отправляет запрос в Flask через JavaScript и обновляет только нужные части страницы. Полная перезагрузка не происходит, поэтому место прокрутки сохраняется без скачка наверх. Саму логику добавления, счётчиков и сохранения выполняет Python. В полночь страница обновляется, а Python обнуляет счётчики, если дата поменялась.
